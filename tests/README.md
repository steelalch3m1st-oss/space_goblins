# Тести

Автоматичні перевірки рушія гри (`../index.html`, між мітками
`/*ENGINE-START*/`/`/*ENGINE-END*/`). Кожен тест спершу витягує рушій
із поточного `index.html` (`extract-engine.js`), тож тести завжди
перевіряють актуальний стан гри, а не застарілу копію.

Запуск (Node.js, без залежностей):

```bash
node tests/passability.test.js      # чи кожен день+ускладнення можна пройти
node tests/achievements.test.js     # чи кожне досягнення досяжне й не автоматичне
node tests/partial-pass.test.js     # чи працює механіка часткового зарахування
```

Очікуваний результат на момент останньої перевірки (2026-11-14):

- `passability.test.js` — 89 із 89 комбінацій «день + ускладнення» проходяться.
- `achievements.test.js` — усі 26 перевірених досягнень досяжні й жодне не відкривається автоматично.
- `partial-pass.test.js` — механіка часткового зарахування працює на всіх 5 днях, де вона ввімкнена (0 провалів).

Кожен скрипт завершується з кодом виходу `1`, якщо знаходить проблему —
зручно для CI.
