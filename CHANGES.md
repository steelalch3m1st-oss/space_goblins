# Космічна зміна: що змінено у візуальній версії («Піксельний місяць»)

Гілка git: `pixel-moon-style` (базовий коміт на `main` це збірка до змін).
Гра це один файл `index.html`. Відкривати через будь-який локальний сервер або двічі клікнути (шрифти й Sortable тягнуться з CDN).

## Що зроблено
- Єдиний стиль: чорний / білий / сірі, прямі кути, піксельні спрайти, Handjet (заголовки) + Press Start 2P (текст 8/10/12 px).
- Спрайти: сітки символів → SVG `rect` (`crispEdges`), Scale2x для піктограм і астронавтів, дизер Баєра 8x8 для куль і рельєфу.
- Фон: зорі (CSS, steps) і планета-спрайтлист на 12 кадрів. Рухається лише фон.
- Спрощення: один гравець, одна місія на планету (МКС «Будні станції», Місяць «Apollo 11», Марс «CHAPEA») по 2 дні.
  День 1 навчальний (без дедлайнів і ускладнень). Дані місій не видалено, фільтри на старті (`simplifyMission`, `UI_MISSION`, `UI_DAYS`).
- Ціль місії (`MISSION_GOAL`) і ресурс «Радіація» (`RAD`): шкала мети, доза за місію, дилема з необов'язковими завданнями.
- Екран планування, варіант A: смужка дня зверху, картки завдань у вкладках, список обраних нижче, залежності пунктиром.
- Мінімум ліній і тексту: підказки в `?`, розкривні блоки, один верхній рядок.
- Мова UA / EN: перемикач на головному екрані, англійський словник `EN_DICT` у `index.html` (шар перекладу на DOM).
- Звук діалогу диспетчера (WebAudio), без озвучки голосом.

## Що перевірити вручну
- Тести рушія (потрібен Node): `node tests/passability.test.js`, `achievements.test.js`, `partial-pass.test.js`.
  Частина досягнень (за 7 місій тощо) тепер недосяжна, бо у грі 3 місії по 2 дні.
- Мобільний вигляд (390x844): перевірено лише програмно.
- Англійський переклад вичитати носієм (фрази зі шматків можуть мати незграбний порядок слів).
- Дані NASA в `NASA_DATA` внесені вручну й позначені `verify:true` (див. `data/README.md`).

## Відомі обмеження
- Живі запити до DONKI / RadLab з браузера не використовуються (недоступні під час розробки).
- Спрайт-листи планет генеруються в браузері на canvas, а не заздалегідь (PNG-файлів немає).
- Піктограми лише подвоєні за роздільністю, не перемальовані заново.

## Оновлення 15.11.2026 (UX-переробка на актуальній збірці)
- **Головна:** великі підписи МКС / МІСЯЦЬ / МАРС над картинками, МКС тепер усередині станції; перемикач підказок по центру; прибрано пояснювальні тексти.
- **Вступ до місії:** ступінчаста анімація (посадка на Місяць / Марс, станція на орбіті), одноразова, є «Далі».
- **Брифінг:** одна коротка репліка (мета дня) і, за потреби, ускладнення. Без плашки мети й навантаження.
- **Планування:** перетягни іконку завдання на широку шкалу часу; знімати можна перетягуванням геть, хрестиком або Delete; клавіші ← → міняють порядок. Клік по смужці над шкалою ставить прапорець «тут краще не працювати». Угорі три чипи: Мета, Проблема, Вимоги (деталі при наведенні). Іконки мають опис при наведенні.
- **Пауза між діями:** завжди 10 хв (`GAP_MIN` у рушії), замість переходів за відстанню.
- **Симуляція:** «ЗЛАМ» → «ПРОВАЛ»; кадри з'являються по ходу, без порожніх клітинок; назви зон українською.
- **Міні-ігри:** з `minigames/` (окремі HTML від колеги), через iframe і `postMessage` (`forpost:minigame-complete`). Перед грою екран «Почати / Пропустити», після неї результат і «Далі». Мапа в `MG` (у рушії):
  - МКС д.1: аналіз крові, центрифуга, вантаж Cygnus, (бонус) фото з Купола; д.2: фільтри, PMM, маніпулятор, укриття (подія).
  - Місяць: LRRR, перевірка систем, гіроплатформа.
  - Марс: обслуговування скафандра, промивка труби.
  Інші ігри з архіву (station, iss, ice, storm, shield, greenhouse, dust, tower) не підключено: у поточних 3 місіях немає відповідних завдань.
- Видалено застарілі міні-ігри, SortableJS, старий екран вибору місії.

## Локальний запуск
`powershell -File tools/serve.ps1 -Port 8765` і відкрити http://localhost:8765/ (iframe з міні-іграми краще працюють через сервер, ніж із `file://`).

## Увага для тестів
Через фіксовану паузу 10 хв 7 комбінацій «день+ускладнення» у НЕАКТУАЛЬНИХ місіях (iss-power, a17, chapea д.4 тощо) більше не мають розв'язку в `tests/passability.test.js`. Усі 15 комбінацій актуальних трьох місій проходні. Тести з Node не запускались (Node немає).

## Оновлення: правки за відгуком
- «?» відкриває підказку біля кнопки; «Проблема» перенесена зліва біля «Брифінгу»; по центру Мета / Вимоги / Навантаження; «!» → «Цікаві факти».

- Вибір місії: назви під картинками, більший шрифт. Диспетчер: деталізоване обличчя, рот анімується під «бла-бла».
